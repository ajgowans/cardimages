# Card Atlas web images

Browser-ready card images for [Card Atlas](https://github.com/ajgowans/pokemon).

Files are generated from the checksum-verified local master archives and keep the complete card frame visible. They are arranged as:

```text
thumb/{set-id}/{card-id}.webp
detail/{set-id}/{card-id}.webp
```

The repository contains image derivatives only. Catalogue metadata, source links, audit reports and application code live in the main Card Atlas repository. Pokémon and Magic: The Gathering artwork, names and related marks remain the property of their respective rights holders. This is an unofficial project and no affiliation or endorsement is claimed.
